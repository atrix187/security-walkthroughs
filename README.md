# 🛡️ Security Walkthroughs

> A personal collection of write-ups for CTF challenges and penetration testing machines across multiple platforms. Each write-up documents my methodology, tools, vulnerabilities exploited, and lessons learned.

---

## 📁 Repository Structure

```
security-walkthroughs/
│
├── HTB/                  # Hack The Box machines & challenges
├── THM/                  # TryHackMe rooms
├── PicoCTF/              # PicoCTF challenges
└── ...                   # More platforms coming
```

Each platform folder contains individual write-ups named after the machine or challenge.

---

## ⚠️ Disclaimer

All write-ups in this repository are for **educational purposes only**. Every machine and challenge documented here is part of a legal, authorized platform (HTB, THM, PicoCTF, etc.). Do not use any of these techniques against systems you do not have explicit permission to test.
